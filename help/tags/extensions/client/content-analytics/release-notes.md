# Adobe Content Analytics拡張機能リリースノート

次に、Content Analytics タグ拡張機能のリリースノートのリストを示します。

| バージョン | 日付 | 修正点 |
|---|---|---|
| 1.0.52 | 2026年4月27日（PT） | <ul><li>CSSがDOM内の要素の背景に画像を読み込むアセットのトラッキングを追加しました。</li><li>[maps.googleapis.com](https://maps.googleapis.com)と[mapsresources-pa.googleapis.com](https://mapsresources-pa.googleapis.com)を含むハードコードされた`permanentlyBlockedURLs`配列を追加しました。 これらのURLは、Content Analytics ライブラリでは、デフォルトで常にブロックされます。</li><li>XDM データ収集要求に`idSource`および`channel` フィールドを追加しました。</li></ul> |
| 1.0.51 | 2026年3月13日（PT） | <ul><li>ページ間を移動する際に`experienceIDs`がキャッシュされる可能性がある軽微なバグを修正しました。</li><li>エクスペリエンスのクエリ文字列パラメーターの取得に関する問題を修正しました。 クエリパラメーターは次のように機能します。<ul><li>クエリパラメーターフィールドが空です。エクスペリエンス IDにクエリ文字列パラメーターが取り込まれません。</li><li>クエリパラメーターは明示的に定義されます（例えば、1、2、3）。これらのクエリ文字列パラメーターと値のみがエクスペリエンス IDに取り込まれます。</li><li>クエリパラメーターがワイルドカード （`.*`）に設定されています。document.location.search文字列全体がURLに含まれます。</li></ul></li></ul> |
| 1.0.49 | 2025年9月12日（PT） | <ul><li>ユーザーにデータストリーム権限がない場合に、タグ拡張機能UIがまったく読み込まれない軽微なバグを修正しました。 UIでは、**[!UICONTROL Choose from list]** データストリームオプションに権限警告が表示されるようになりました。引き続き、ユーザーが値を手動で入力できるようにします。</li><li>l10nのパスの問題を更新しました。</li><li>画像以外の親の子要素である一部の画像が、それらの子画像要素のアセットクリックを正しくキャプチャできない問題を修正しました。</li><li>ユーザーが`alloy`とは異なるインスタンス名を持つタグでWebSDKが設定されている場合、Content Analytics ライブラリはWebSDK ライブラリの最初のインスタンスを検出し、それを使用してContent Analytics イベントを送信します。</li></ul> |
| 1.0.48 | 2025年8月25日（PT） | <ul><li>ドキュメントのシャドウルート DOM要素内のアセットを追跡するためのサポートを追加します。</li></ul> |
| 1.0.47 | 2025年7月23日 | <ul><li>エクスペリエンスが有効になっていないときに発生し、エクスペリエンスの正規表現チェックが失敗するバグを修正しました。 この問題により、Content Analytics データを収集できませんでした。</li><li>Experience Cloudで主要なデフォルト言語が設定されていない一部のユーザーに対して、タグ UIが表示されないデフォルト言語の設定に関する問題を解決しました。</li></ul> |
| 1.0.46 | 2025年6月18日（PT） | <ul><li>実稼動データストリームが存在しない場合に、拡張機能設定を保存しようとしたときにトースト通知を追加しました。</li><li>代わりにコンソールに細分化されたペイロードの内容を配置することで、Content Analytics ペイロードの表示に関する問題を一時的に修正しました。</li><li>拡張機能UIにローカライゼーションのサポートを追加しました。</li><li>拡張機能UI コンテンツの周囲に追加のパディングが発生するCSSの問題を部分的に修正しました。</li></ul> |
| 1.0.45 | 2025 年 4 月 14 日 | <ul><li>ページビューイベントの待機中にContent Analytics イベントを保持することに関する設定設定のいくつかのバグを修正しました。 Content Analyticsは、初期設定では、最初のページビューイベントが発生するまでイベントを起動するのを待ちます。</li></ul> |
| 1.0.44 | 2025年3月31日 | <ul><li>AppMeasurement統合の最初のイテレーション</li><li>このバージョンでは、特定のリクエスト（ページビューなど）のフィルタリングはまだサポートされていませんが、今後のアップデートでこの機能が追加される可能性があります。 現在、ページに最初に見つかったAppMeasurement インスタンスが使用されています。</li></ul> |
| 1.0.43 | 2025年3月10日（PT） | <ul><li>最初の拡張機能リリース。</li></ul> |
