# MCP クライアントの操作（Beta） {#rtcdp-mcp}

Adobe Real-Time CDPのMCP統合を利用すれば、API呼び出しを記述したり、製品画面を移動したりすることなく、平易な言語のプロンプトを使用して、オーディエンス、宛先、アクティベーションの正常性をクエリできます。 このページでは、統合がどのように機能するのか、何ができるのか、どのように始めればよいのかについて説明します。

>[!AVAILABILITY]
>
>Real-Time CDP MCP サーバーは、サポートされているMCP クライアントおよびアプリプラットフォーム（Claude、ChatGPT、Claude Code、Codex、Cursor、VS Codeなど）にユーザーがインストールおよび設定する&#x200B;**リモート HTTP トランスポート サーバー**&#x200B;として配布されます。 認証は、**ブラウザーベースのログインフロー**&#x200B;を通じて処理されます。クライアントが最初にサーバーに接続すると、デフォルトブラウザーが開き、Adobeの資格情報でログインしてアクセスを許可できます。

## モデルコンテキストプロトコルとは何ですか？ {#mcp-overview}

マーケティング、データ、顧客体験の各チームは、日々の作業を合理化するために、チャットベースのアプリケーションや開発者ツール（Anthropic Claude、OpenAI ChatGPT、Cursor、Microsoft Copilot Studioなど）への依存度を高めています。 これらのアプリケーションは、**Model Context Protocol （MCP）**&#x200B;をサポートしています。これは、アプリケーションがバックエンドツールを大規模言語モデル（LLM）に統一された方法で公開できるようにするオープンスタンダードです。

Real-Time CDPは、MCP互換アプリケーション内でオーディエンス、宛先、アクティベーションの操作を直接表示するMCP サーバーを提供するようになりました。 Real-Time CDPとMCPを連携することで、Adobe Experience Platform REST APIに対してクエリを作成したり、複数のUI画面を操作したりすることなく、様々なペルソナが同じセグメンテーションデータやアクティベーションデータを利用して共同作業をおこなうことができます。 顧客は自分の意図を対話的に説明でき、LLMが適切なMCP ツールを呼び出せます。

## 主な機能 {#mcp-capabilities}

Real-Time CDP MCP サーバーでは、AI アシスタントから直接、オーディエンスと宛先を検査、要約、トラブルシューティングできます。 すべての操作は&#x200B;**読み取り専用**&#x200B;です。MCP サーバーサーフェスは、APIを平易な言語の回答として取得するため、次のことが可能です。

* **オーディエンスをすばやく可視化** — メニューを移動したり、レポートを手動で取得したりすることなく、オーディエンスの定義、ライフサイクルの状態、名前空間をわかりやすい言語で確認できます。
* **アクティブ化する前にオーディエンスサイズを見積もる** — オーディエンスの構築にコミットする前に、PQLまたはSDD セグメントクエリのメンバーシップ数と信頼区間をプレビューします。
* **アクティベーションポートフォリオを監査** — JSONを解析したり、製品画面にジャンプしたりすることなく、設定済みの宛先、データフローのフィード、各フローの背後にあるソース/ターゲット接続を確認します。
* **アクティベーションの問題を早期に特定** – 要求した瞬間にサーフェスが失敗または処理中の宛先が実行されるため、チームは迅速に行動できます。
* **ライブデータを中心としたコラボレーション** — マーケター、データエンジニア、ステークホルダーは、AI アシスタントを通じて同じライブ Real-Time CDP データをクエリできるため、調整、決定、連携が容易になります。

## 利用可能なツール {#mcp-tools}

次のツールは、Real-Time CDP MCP サーバーによって公開されます。

| ツール | 説明 |
| --- | --- |
| **既存オーディエンスの検索** | オプションのフィルター（名前、エンティティタイプ、ライフサイクルの状態、名前空間、オリジン）を使用してオーディエンスを一覧表示したり、IDで特定のオーディエンスを取得したりできます。 |
| **オーディエンスメンバーシップのプレビュー** | 信頼区間メタデータを含む、セグメントクエリのサイズの見積もり（プロファイルオーディエンスの場合はPQL、リレーショナル/アカウントオーディエンスの場合はSDD）。 |
| **宛先タイプのリスト** | サンドボックスで使用可能な宛先コネクタタイプのカタログを表示します。 |
| **設定済みアカウントのリスト** | 設定された宛先アカウント（ベース接続）とその認証の詳細を参照します。 |
| **設定済みの宛先のリスト** | 宛先データフローを参照し、名前、状態、フロー仕様、またはソース/ターゲット接続でフィルタリングできます。 |
| **Source Connectionsの一覧** | 宛先データフローのデータセットマッピング情報を保持するソース接続を検査します。 |
| **ターゲット接続のリスト** | 宛先のデータ形式とパス設定を保持するターゲット接続を検査します。 |
| **ライセンス認証の実行** | 宛先データフローの実行履歴、フローID、ステータス（成功、失敗、進行中）、完了時間範囲でフィルタリング可能を確認します。 |

>[!NOTE]
>
>すべてのツールは&#x200B;**読み取り専用**&#x200B;です。 書き込み操作（オーディエンス、宛先、またはデータフローの作成、更新、削除）は、現在のBeta リリースではサポートされていません。

## 前提条件 {#mcp-prerequisites}

Real-Time CDP MCP サーバーをMCP クライアントに接続する前に、次の点を確認してください。

* アクティブなReal-Time CDP ライセンスがあります。
* リモート MCP サーバーまたはカスタム MCP アプリ（Claude、ChatGPT、Claude Code、Codex、Cursor、VS Codeなど）に接続できる、サポートされているクライアントにアクセスできます。
* 組織IDと、クエリするサンドボックスの名前があります。
* オーディエンス、宛先、フローサービスエンティティを表示するために必要な権限をAdobe Experience Platformに持っています。

## Real-Time CDP MCP サーバーへの接続 {#mcp-connect}

>[!NOTE]
>
>この統合はBetaにあります。 顧客のメニュー、プランの要件、管理者の管理機能は、アプリケーションやバージョンによって異なります。

まず、次の項目を確認してください。

* MCP サーバーエンドポイント URL: `https://rtcdp-mcp.adobe.io/mcp`。
* Adobe ユーザーが対象のExperience Platform組織とサンドボックスにアクセスできることを確認します。

Real-Time CDP MCP サーバーは&#x200B;**リモート HTTP MCP サーバー**&#x200B;です。 すべてのクライアントで、セットアップは同じパターンに従います。

1. サーバーURLを追加します。
2. 接続を保存または有効にします。
3. クライアントが初めてツールを呼び出すときに、**ブラウザーベースのAdobe ログイン**&#x200B;を完了します。
4. 各リクエストに`imsOrgId`と`sandboxName`を指定します。

### UI ベースのクライアントへのインストール {#mcp-connect-ui}

#### クロード

`claude.ai`とClaude Desktopの場合は、**を使用してReal-Time CDP MCP サーバーを** カスタムコネクタ `https://rtcdp-mcp.adobe.io/mcp`として追加します。 個別のClaude プランで、**カスタマイズ/コネクタ**&#x200B;の下に追加します。 グループ版およびエンタープライズ版のプランでは、所有者が最初に&#x200B;**組織設定/コネクタ**&#x200B;の下に追加する必要がある場合があります。その後、各ユーザーが独自のクラウド設定で接続します。 設定が完了したら、会話でコネクタを有効にし、最初の使用時にAdobe ブラウザーログインを完了します。

#### ChatGPT

ChatGPTで、**を使用してReal-Time CDP MCP サーバーを** カスタムアプリ/コネクタ `https://rtcdp-mcp.adobe.io/mcp`として追加します。 ChatGPT プランによっては、**開発者モード**&#x200B;とワークスペース管理者の承認が必要になる場合があります。 アプリ/コネクタを作成または有効にした後、**Settings > Apps**&#x200B;または&#x200B;**Settings > Apps &amp; Connectors**&#x200B;から接続し、プロンプトが表示されたらAdobe ブラウザーログインを使用して認証します。

#### その他のUI ベースのクライアント

Cursor、VS Code、リモート MCPをサポートする他のデスクトップおよびweb アプリケーションなどのクライアントの場合は、Real-Time CDP MCP サーバーを&#x200B;**リモート HTTP** サーバーとして追加し、`https://rtcdp-mcp.adobe.io/mcp`を使用します。 クライアントがオプションのヘッダーまたはベアラートークンをサポートしている場合は、Adobeが特に指示しない限り、それらを空のままにします。認証は、最初の使用時にブラウザベースのAdobe サインインフローを通じて処理されます。

### テクニカルクライアントへのインストール {#mcp-connect-technical}

#### クロード・コード

ターミナルからサーバーを追加します。

```bash
claude mcp add --transport http rtcdp https://rtcdp-mcp.adobe.io/mcp
```

次に、Claude Codeを起動し、以下を実行します。

```text
/mcp
```

`rtcdp` サーバーを選択し、ブラウザーでAdobe ログインフローを実行します。 `claude.ai`でサーバーを既に追加している場合、両方で同じアカウントを使用している場合は、同じサーバーがClaude Codeに自動的に表示されることもあります。

#### Codex

ターミナルからサーバーを追加します。

```bash
codex mcp add rtcdp --url https://rtcdp-mcp.adobe.io/mcp
```

サーバーの認証：

```bash
codex mcp login rtcdp
```

設定を確認します。

```bash
codex mcp list
```

サーバーを`~/.codex/config.toml`に直接追加することもできます。

```toml
[mcp_servers.rtcdp]
url = "https://rtcdp-mcp.adobe.io/mcp"
```

### 必須のリクエストパラメーター {#mcp-connect-params}

すべてのツール呼び出しには、リクエストをスコープする2つのパラメーターが必要です。

* `imsOrgId` – 下流のExperience Platform API呼び出しで`x-gw-ims-org-id` ヘッダーにマッピングされた組織ID。
* `sandboxName` — `x-sandbox-name` ヘッダーにマッピングされたExperience Platform サンドボックス名。

## 既知の制限事項（Beta） {#mcp-limitations}

次の制限は、[!DNL Adobe Real-Time CDP] MCP サーバーの現在のBeta リリースに適用されます。

| 制限事項 | 説明 | 回避策 |
| --- | --- | --- |
| **読み取り専用サーフェス** | MCP サーバーは取得APIのみを公開します。 オーディエンス、宛先、またはデータフローを作成、更新、アクティベート、または削除することはできません。 | Real-Time CDP UIまたはAEP REST APIを使用して書き込み操作を行います。 |
| **エンゲージメントまたは配信指標がありません** | MCP サーバーは、ダウンストリーム配信の統計、エンゲージメント、またはコンバージョン指標を宛先プラットフォームから返しません。 | エンゲージメントとコンバージョンのデータには、配信先プラットフォーム独自のレポート、Customer Journey Analytics MCP、Adobe Analytics MCPを使用できます。 |
| **セグメントクエリは外部で作成する必要があります** | `Preview Audience Membership`には入力として有効なPQLまたはSDD式が必要です。MCP サーバーはクエリを作成しません。 | セグメントビルダーUIまたはSegmentation Service APIを使用してPQL/SDD式を作成し、MCP プロンプトに貼り付けます。 |
| **継続トークンを使用したページネーション** | リストツールは、ページ分割された結果を返します。 非常に大きなサンドボックス全体で完全な列挙を行うには、`continuationToken`回の呼び出しを連鎖させる必要があります。 | リスト全体を列挙するのではなく、フィルター（名前、状態、接続仕様、時間範囲）を使用してクエリを絞り込みます。 |
| **アクティベーション実行のフィルタリングは時間ベースのみです** | `Inspect Activation Runs`は、ステータスと完了タイムスタンプ （epoch ms UTC）によるフィルタリングをサポートしていますが、エラータイプや宛先プラットフォームによるフィルタリングはサポートしていません。 | 最初に`flowId`でフィルターを実行し（`List Configured Destinations`から取得）、スコープを特定の宛先に実行します。 |
| **地域の設定が必要** | MCP ゲートウェイがユーザーのリージョンに設定されていない場合、ツール呼び出しはHTTP 403 「User region is missing」で失敗します。 | 最初に使用する前に、Adobe担当者に連絡して、お客様の地域にゲートウェイが設定されていることを確認してください。 |

## よくある質問 {#mcp-faq}

+++どのMCP クライアントがサポートされていますか？

Real-Time CDP MCP サーバーは、リモート MCP サーバーまたはカスタム MCP アプリケーション（Claude、ChatGPT、Claude Code、Codex、Cursor、VS Codeなど）に接続できるサポート対象のクライアントで動作します。 セットアップフローはクライアントによって異なります。UI ベースのクライアントは通常、設定からサーバーを追加しますが、Claude CodeやCodexなどのテクニカルクライアントはコマンドラインまたは設定ファイルからサーバーを追加できます。
+++

+++認証の仕組み？

認証は、**ブラウザーベースのログイン**&#x200B;を通じて処理されます。 MCP クライアントが最初にツールを呼び出すと、デフォルトのブラウザーが開き、Adobe ログインページが表示されます。 クライアントを認証および認証した後、セッションが確立され、後続のツール呼び出しがそれを再利用します。 API キーや長期間有効な資格情報をクライアント設定に保存する必要はありません。
+++

+++MCP経由でアクセスできるReal-Time CDP オブジェクトは何ですか？

オーディエンス、宛先タイプ、設定済みの宛先アカウント、宛先データフロー、ソース接続とターゲット接続、アクティベーションの実行履歴にアクセスできます。 操作は読み取り専用（取得API）です。書き込み操作は現在のリリースではサポートされていません。
+++

+++Real-Time CDP MCP サーバーを使用するには、開発者アクセス権が必要ですか？

いいえ。 MCP サーバーは、マーケティングとテクノロジーの両方のペルソナ向けに設計されています。 マーケターは、サポートされているMCP クライアントで自然言語プロンプトを使用してMCPと対話できます。一方、データエンジニアや開発者は、MCPをサポートする開発者ツールでMCPを使用できます。
+++

+++データはMCP クライアントプロバイダーに送信されますか？

プロンプトを送信すると、MCP クライアントは、関連するコンテキスト（MCP サーバーから返されるReal-Time CDP データを含む）をモデルに送信して処理する場合があります。 本番データに接続する前に、MCP クライアントプロバイダーのプライバシーおよびデータ処理ポリシーを確認してください。
+++

+++Real-Time CDPでどのような権限が必要ですか？

クエリするオブジェクト（オーディエンス、宛先、フローサービスエンティティ）に対して、少なくとも&#x200B;**表示**&#x200B;権限が必要です。 MCP サーバーは読み取り操作のみを実行するため、書き込み権限は必要ありません。 現在のアクセス レベルが不明な場合は、[!DNL Adobe Experience Platform]管理者にお問い合わせください。
+++

+++サンドボックス環境でMCP サーバーを使用できますか？

はい。 すべてのツール呼び出しには`sandboxName` パラメーターが必要なので、MCP サーバーは常に[!DNL Adobe Experience Platform] サンドボックス設定を尊重します。 プロンプトで名前を指定することで、アクセスできるサンドボックスをクエリできます。
+++

+++プレビューオーディエンスメンバーシップと既存オーディエンスの検索の違いは何ですか？

`Search Existing Audiences`は、既に作成され、サンドボックスに保存されているオーディエンスを返します。 `Preview Audience Membership`は、生のPQLまたはSDD セグメント式を取り出し、サイズ推定値を返します。この値は、クエリのサイズを&#x200B;*前*&#x200B;に設定する場合に便利です。
+++

+++アカウントオーディエンスとプロファイルオーディエンスの両方をクエリできますか？

はい。 `Search Existing Audiences`と`Preview Audience Membership`の両方で、エンティティ型パラメーターをサポートしています。 プロファイルオーディエンスはPQLまたはSDDで表現できます。アカウントオーディエンスは常にSDD （リレーショナル）構文を使用します。
