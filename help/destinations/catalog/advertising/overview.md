# 広告の宛先の概要 {#advertising-destinations}

## 概要 {#overview}

[!DNL Adobe Experience Platform]をデマンドサイドプラットフォーム （DSP）、サプライサイドプラットフォーム （SSP）、広告ネットワークなどの広告プラットフォームに接続して、これらのプラットフォームに既知および仮名のオーディエンスを共有します。

広告の宛先に接続すると、オーディエンスは ID として宛先プラットフォームに送信され、宛先プラットフォームで知られている ID にマッピングされます。

## 新しい広告配信先への接続 {#connect-destination}

キャンペーンの広告宛先にオーディエンスを送信するには、Experience Platformが最初に宛先に接続する必要があります。 新しい宛先の設定について詳しくは、[宛先の作成に関するチュートリアル](../../ui/connect-destination.md)を参照してください。
