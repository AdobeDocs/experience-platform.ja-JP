# [!DNL Deltashare]

[!DNL Deltashare] ソースコネクタを使用すると、[!DNL Databricks Delta Sharing] サーバーへの安全な接続を確立し、Adobe Experience Platformで仮想データセットを作成できます。 この機能を使用すると、仮想データセットに対するクエリを実行し、外部テーブルを調べてエクスペリエンスデータモデル（XDM）スキーマにマッピングし、Experience Platformのアプリケーションやサービスで活用できます。 [!DNL Deltashare] を通じて、データセットの物理的な取り込みを回避し、重複、ストレージコスト、運用オーバーヘッドを削減できます。
