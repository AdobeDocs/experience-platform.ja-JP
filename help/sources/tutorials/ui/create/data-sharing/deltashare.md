# UI での [!DNL Deltashare] ソースコネクタの使用 {#use-deltashare-in-the-ui}

>[!CONTEXTUALHELP]
>id="platform_sources_deltashare_schema"
>title="スキーマの構造"
>abstract="先に進むとスキーマを変更できなくなるので、スキーマ構造を必ず確認してください。"

このガイドでは、Adobe Experience Platform ユーザーインターフェイスで[!DNL Deltashare] ソースコネクタを使用する方法について説明します。

**メモ：** **次へ**&#x200B;を選択すると、選択したスキーマ構造を変更できなくなります。

既に&#x200B;**次の**&#x200B;を選択し、スキーマ選択ステップを過ぎて移動した場合、前のステップに戻ると、選択したスキーマを更新できなくなります。 スキーマを変更するには、データフロー設定プロセスを再起動し、最初の手順から開始する必要があります。
