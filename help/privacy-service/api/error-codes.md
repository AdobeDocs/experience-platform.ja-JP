# Privacy Service エラーコード {#privacy-service-error-codes}

このリファレンスを使用して、Privacy Service ジョブの結果を特定し、エラーを診断し、**Adobe Experience Platform**&#x200B;でプライバシージョブを送信または監視する際の適切な次の手順を決定します。 プライバシージョブを作成、送信、監視する方法については、[ プライバシージョブのエンドポイントガイド ](./privacy-jobs.md)または[Privacy Service UI ユーザーガイド ](../ui/user-guide.md)を参照してください。

Privacy Serviceのエラーコードは、安定したパブリックコントラクトです。 各エラーコードは、プログラマティック処理や運用ワークフローに依存できる障害または完了状態を一意に識別します。

自動化を構築する場合やワークフローを監視する場合は、次の保証が適用されます。

* エラーコードは、公開後も安定しています。
* エラーメッセージは、明瞭性を向上させるために変更される場合がありますが、コード値は変更されません。
* 新しいエラーコードは時間の経過とともに追加される可能性があります。既存のコードは再利用されません。

自動化や意思決定ロジックを実装するには、メッセージテキストではなくエラーコードを使用します。 ポーリングまたはメッセージ文字列に依存せずに、プライバシージョブの効率的な処理、ジョブの状態の監視、エラーの処理に関するガイダンスについては、[Privacy Serviceのベストプラクティス ](../best-practices.md)を参照してください。

## エラー応答形式 {#error-response-format}

Privacy Serviceは、ジョブおよびリクエスト応答のエラー情報を返します。 応答は、応答ペイロードに数値エラーコードおよび人間が読み取り可能なメッセージを含む。

エラーコードは、信頼できる結果を伝えます。 このメッセージには、トラブルシューティング用の追加のコンテキストが表示されます。

このドキュメントでは、各エラーコードの意味と意図について説明します。 フィールドレベルの応答スキーマとリクエストの詳細については、[Privacy Service API ドキュメント ](https://developer.adobe.com/experience-platform-apis/references/privacy-service/)を参照してください。

## エラードメイン {#error-domains}

エラーコードは、問題をより迅速に診断するのに役立つ、機能ドメインごとにグループ化されています。

このドキュメントで使用されるドメインには、次のものが含まれます。

* **リクエスト検証**：リクエストの形式が正しくないか、無効な値が含まれています。 リクエスト構造と検証要件については、[ プライバシージョブエンドポイントガイド ](./privacy-jobs.md)を参照してください。
* **認証とプロビジョニング**：組織またはユーザーに必要なアクセス権がありません。 役割ベースの権限の要件を確認するには、[権限の管理](../permissions.md)を参照してください。
* **IDと適用性**：識別子または名前空間はリクエストに適用できません。 サポートされているID タイプと名前空間の要件については、[ プライバシーリクエストのID データ ](../identity-data.md)を参照してください。
* **レート制限**：送信ボリュームがプラットフォームの制限を超えています。 このエラーが発生した場合は、送信率を下げて、もう一度試してください。
* **データへのアクセスと処理**: システムは、要求されたデータにアクセスまたは処理できません。 一般的な原因と解決手順については、[ トラブルシューティング ガイド ](../troubleshooting-guide.md)を参照してください。
* **暗号化とキー管理**：必要な暗号化キーを使用できません。 キーのアクセス、設定、回復に関するガイダンスについては、[顧客管理キー](../../landing/governance-privacy-security/customer-managed-keys/overview.md)を参照してください。
* **ジョブ実行状態**: ジョブは完全に、部分的に、またはエラーが発生して完了しました。 ジョブの状態カテゴリとその意味については、[ プライバシージョブ エンドポイントガイド ](./privacy-jobs.md#status-categories)を参照してください。

>[!NOTE]
>
>ドメインの割り当ては、内部サービスの境界ではなく、エラーコードの意図を反映します。

## エラーコード参照 {#error-code-reference}

次の表に、すべてのパブリック Privacy Service エラーコードを示します。

| エラーコード | HTTP ステータス | タイトル | 説明 |
| ---------- | ----------- | ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1000-400 | 400 | 書式設定エラー | 指定したアプリケーションの1つ以上のデータ値に書式設定の問題があります。 詳細については、ジョブの詳細を確認してください。 |
| 1001-400 | 400 | 許可されていません | 組織がプロビジョニングされていません。 詳細については、管理者にお問い合わせください。 |
| 1010-400 | 400 | 権限がありません | このアクションを実行するために必要な権限がありません。 管理者に連絡してアクセスをリクエストしてください。 |
| 1020-400 | 400 | アップロードとアーカイブの失敗 | アクセス データのアップロードとアーカイブ中に問題が発生しました。 アクセス データをアップロードして、もう一度試してください。 |
| 1021-400 | 400 | ジョブの失敗 | リクエストから作成された1つ以上のプライバシージョブが失敗しました。 詳細については、失敗したジョブの詳細を確認してください。 |
| 1022-400 | 400 | データアクセスの失敗 | 指定されたデータへのアクセス中に問題が発生しました。 詳細については、ジョブの詳細を参照してください。 |
| 1023-400 | 400 | データアクセスの失敗 | 指定されたデータセット IDへのアクセスまたは検索中に問題が発生しました。 指定されたIDが有効であることを確認してから、もう一度試してください。 |
| 1024-400 | 400 | 予期しないエラー | 予期しないエラーが発生しました。詳細については、ジョブの詳細を参照してください。 |
| 1030-400 | 400 | ドキュメントのレート制限を超えました | ワークロードがドキュメントのレート制限を超えました。 送信率を下げてから、もう一度試してください。 |
| 1040-400 | 400 | キー暗号化アクセスの失敗 | データストアが暗号化され、キーへのアクセスが取り消されたため、データを処理できませんでした。 お客様のキーへのアクセス権を復元するには、Key Vault管理者にお問い合わせください。 |
| 6000-200 | 200 | 成功 | ジョブが正常に完了しました。 ジョブの詳細を確認して、処理済みのレコードと結果を確認します。 |
| 6051-200 | 200 | プロビジョニングされていない | あなたの組織はリクエストされたアプリケーション用にプロビジョニングされていません。 リクエストは適用できません。 |
| 6052-200 | 200 | ユーザーIDが見つかりません | 一部のユーザーIDが見つからず、不明なユーザーIDはこの製品には適用されません。 ユーザーIDが有効であることを確認してから、もう一度試してください。 |
| 6053-200 | 200 | 無効な名前空間 | 指定されたID名前空間は、このアプリケーションには無効です。 システムが認識する名前空間を使用します。 |
| 6054-200 | 200 | 一部完了 | 該当するデータのジョブは完了しましたが、一部のデータはリクエストに該当しませんでした。 詳細については、ジョブの詳細を参照してください。 |
